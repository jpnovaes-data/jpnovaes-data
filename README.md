## Projeto em destaque

### Pipeline de Indicadores Econômicos do Brasil

Pipeline automatizado que coleta dados do Banco Central do Brasil, valida as informações, armazena os dados em PostgreSQL, realiza transformações com dbt e publica um dashboard de indicadores econômicos.

- Ingestão automatizada via API do Banco Central.
- Validação e testes de qualidade dos dados.
- Carga idempotente em PostgreSQL.
- Transformações analíticas com dbt.
- Infraestrutura como código com Terraform.
- CI/CD com GitHub Actions.
