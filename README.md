## Projeto em destaque

### Pipeline de Indicadores Econômicos do Banco Central

Pipeline automatizado para coleta, armazenamento, transformação e publicação de indicadores econômicos brasileiros, incluindo câmbio, juros e inflação.

**Tecnologias:** Python, pandas, API do Banco Central, PostgreSQL, dbt, Terraform e GitHub Actions.
